# blue41 PES2021 Mod Studio

**All-in-one modding tool for eFootball PES 2021** and its patches (e.g. SP Football Life): Sider settings and module
manager, custom crowd chants for any team, No Injuries and Become a Legend helpers — with a backup and an undo for
every change it makes.

**Website:** https://limadiogenes.github.io/blue41_PES2021_MOD_STUDIO/
**Download:** Early Access v0.1.0 — coming soon on the [Releases](../../releases) page.

## Features

- **Sider, made easy** — every `sider.ini` setting explained in plain English, with the right control for each value
  (switches, key pickers, installed fonts, colour picker) and a before/after text view.
- **Modules & content roots** — switch Lua modules and livecpk folders on/off and reorder them without editing text.
- **Custom crowd chants** — drop MP3/WAV files on a team; converted, loudness-matched to the game, a different song
  each time; home/away volume, preview, rename. Liverpool and Corinthians sets included.
- **No Injuries** — turn in-match injuries off, Become a Legend included (Sider overlay toggle).
- **Safe by design** — every change backed up, verified and undoable from the Change log.
- **Portable** — no installer, no registry; finds your game, Sider and saves on its own.
