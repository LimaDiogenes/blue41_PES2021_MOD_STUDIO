Control the whole team in Become a Legend

Become a Legend only lets you play your own player and greys out the Game Plan. The studio's full team control module lets you play the whole team and manage it in matches, and your career stays a normal Become a Legend career.

Step by step

The app speaks English, Español and Português (Settings → Language); the names below are the ones you'll see in English.

  1. Open Cheats → Full team control and click Install (backup first, undo from the Change log).
  2. Tick what you want: Control the whole team, Cursor Change in the pause menu, Game Plan editable in matches and Remove the spectator prompt at kick-off.
  3. Start the game and load your career: the module reads these settings when the game starts.
  4. In a match, switch between your players as in any other mode. Pause to choose Cursor Change (Assisted, Semi-Assisted or Manual).
  5. The pause menu now offers the full Game Plan instead of "Check Game Plan": formation, tactics, substitutions, captain and set-piece takers.

Good to know

  • Needs: Sider with its LuaJIT option on (luajit.ext.enabled = 1). Home checks this and links the download if something is missing.
  • While the game runs, use the Sider overlay: Space, select BALFullControl_blue41, then [2] control, [3] Cursor Change, [4] kick-off fix, [5] Game Plan, [0] run the kick-off fix now.
  • If the Captain & set pieces module keeps a captain or takers locked, it puts them back over your Game Plan choice: switch its lock off with [5] in its overlay when you pick them in the game.
  • The module changes the game only in memory while it runs; nothing on disk except adding the module. Turn off removes it.
  • Built and tested on SP Football Life 2026 and 2027.
